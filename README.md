# Bubble Cannon

Аркадная игра: пузырьковая пушка против монстров. 12 миров, 120 уровней, 48 врагов и 12 боссов.
Работает в браузере на ПК и телефоне, установка не требуется.

**Играть:** https://pavlick1292.github.io/bubble-cannon/

## Структура

- `index.html` — страница игры (описание, скриншоты, кнопка запуска).
- `game/` — сама игра: `index.html` + спрайты, фоны и звуки.
- `img/` — картинки для страницы.

## Управление

Мышь или палец: прицеливание и выстрел. Клавиатура не нужна.

## Технологии

Чистый HTML5 + Canvas + JavaScript, без сборки и зависимостей. Звук — WAV, графика — PNG/JPG.
