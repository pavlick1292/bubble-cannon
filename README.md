# Bubble Cannon — страница игры

Сайт-визитка игры Bubble Cannon (аркада для Android: 12 миров, 120 уровней, 48 врагов, 12 боссов).
Живая версия: https://pavlick1292.github.io/bubble-cannon/

Сама игра на сайте не публикуется — только описание, скриншоты текущей сборки и арт.
Актуальная сборка Android лежит в проекте `Desktop\bubles\godot\build\`.

## Структура

- `index.html` — единственная страница: герой Пушок, скриншоты, 12 миров, враги и боссы.
- `img/` — скриншоты, снятые из текущей сборки (`--shot --screen=play|shop|menu`), 720x1280.
- `art/` — спрайты и фоны, выгруженные из проекта Godot.

## Как обновить

1. Скриншоты: `Godot_v4.7.2-stable_win64_console.exe --path <проект> -- --shot --screen=play --level=5`
   (файл `shot.png` в папке проекта), затем положить в `img/`.
2. Любая правка `index.html` → `git commit` → `git push`, GitHub Pages пересобирается сам.
